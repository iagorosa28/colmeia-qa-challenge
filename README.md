# colmeia-qa-challenge

Teste técnico para a vaga de Analista de Testes da ColmeIA.

## Ambiente de teste

- Ambiente: disponibilizado pela empresa
- Credenciais: disponibilizadas pela empresa
- Navegador: Google Chrome
- Sistema operacional: Windows 11
- Data dos testes: 30/09/2026

## Estrutura do repositório

- `tests/` - contém a documentação individual de cada teste realizado.
- `assets/` - contém as evidências dos testes, organizadas em pastas individuais.
